# 🏏 Cricket Performance Analysis – Power BI

## 📊 Project Overview

This project is an interactive **Cricket Performance Analysis Dashboard** created using **Microsoft Power BI**. The dashboard analyzes real-world cricket data for **India vs South Africa**, covering **Batting, Bowling, and Fielding** performance.

The project focuses on data collection, cleaning, transformation, calculated columns, interactive filtering, and visualization to present player-level cricket statistics in an easy-to-understand dashboard.

## 📌 Dashboard Pages

### 🏏 Batting Analysis

The Batting page allows users to select an Indian player using a **dropdown slicer** and view the player's:

* Span
* Strike Rate
* Runs
* Not Outs
* Matches
* Batting Average

The card visuals dynamically update based on the selected player.

## 🔄 Data Preparation

The data was collected from **web-based cricket data sources using URLs** and imported into Power BI.

The project involved:

* Extracting data from web sources
* Data cleaning and transformation using **Power Query**
* Removing and handling unnecessary data
* Formatting and correcting data types
* Creating custom columns
* Creating custom/supporting tables
* Transforming the data into a suitable structure for analysis

## 🧮 Calculated Columns & Interactivity

The project uses **calculated columns created using DAX** to derive additional information from the existing cricket data.

The dashboard uses **slicers and card visuals** to create an interactive experience. When a player is selected from the dropdown slicer, the selection filters the dashboard and the card visuals automatically display the corresponding statistics for that player.

## 🎯 Project Objective

The objective of this project is to demonstrate practical skills in **data extraction, data cleaning, transformation, calculated columns, interactive filtering, and Power BI visualization** using real-world cricket data.

The dashboard provides an interactive way to explore and understand the performance statistics of Indian cricket players across **Batting, Bowling, and Fielding**.
